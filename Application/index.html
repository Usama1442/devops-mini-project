Status: App ready, pipeline coming next

About the project

The goal is to take a simple HTML, CSS, and JavaScript app and practise the full DevOps workflow: version it with Git, host the code on GitHub, package it with Docker, run it on Kubernetes, deploy it to AWS, and automate everything with CI/CD and Ansible.

Technologies

  • LinuxThe operating system most servers run on.
  • GitTracks every change made to the code.
  • GitHubStores the code online and enables teamwork.
  • DockerPackages the app so it runs the same everywhere.
  • KubernetesRuns and manages containers at scale.
  • AWSCloud platform where the app will be hosted.
  • CI/CDAutomatically tests and deploys each change.
  • AnsibleAutomates server setup and configuration.
